Chad's Workflow
Reddit-sourced discovery → Kano classification → human-gated delivery

Pipeline Steps

Discovery to deployment with human review gates
1
Reddit Scrape Agent
Agent scrapes Reddit for user complaints. Raw signal source — unfiltered, direct from users expressing pain.
2
Kano Classification Agent
Agent applies the Kano model to each complaint, classifying it as one of five feature types.
  • Basic — expected; absence causes dissatisfaction
  • Performance — more is better; linear satisfaction
  • Delighter — unexpected; creates delight when present
  • Indifferent — users don't care either way
  • Reverse — wanted by some, disliked by others
3
Confirm Kano Human
Human reviews and confirms the agent's Kano designation. Strategic gate — ensures classification reflects product intent, not just text pattern matching.
4
Create Story Agent
Agent drafts a user story from the confirmed complaint and its Kano designation. Kano type informs how the story is framed — a Basic is written as a fix, a Delighter as an enhancement.
5
Refine Story Human
Human edits and refines the story before handing off to coding. Acceptance criteria, scope, and edge cases defined here.
6
Push to Coding Agent Human
Human explicitly hands the refined story to the coding agent. Intentional gate — human decides when a story is ready to build.
7
Code Story Coding Agent
Agent implements the story. Produces a PR with code changes.
8
Check Staging Human
Human verifies the implementation in a staging environment. Visual and functional check before code review.
9
Review PR Human
Full human PR review — code quality, regression baseline, and edge case testing.
  • Code review
  • Baseline review
  • Edge case testing
✓ Approved
Agent deploys to production.
✗ Rejected
PR returned to coding agent with reviewer notes. Agent recodes and resubmits — loop repeats from step 7.

A Kano Model

A product management framework for classifying features by how they affect customer satisfaction. Used here to prioritize which Reddit complaints become stories.

TypeIf absentIf presentPriority
Basic Strong dissatisfaction Neutral (expected) Fix first
Performance Dissatisfaction Satisfaction (scales) Invest proportionally
Delighter Neutral (unknown) Delight Differentiate
Indifferent Neutral Neutral Deprioritize
Reverse Some prefer it absent Some dislike it Segment carefully

C Human Gate Count

Chad's workflow has 5 human gates — discovery, classification confirm, story refine, push, staging + PR review. Hello Scrum has 3 human gates — Elaborate, Sprint Planning, Start Sprint. Chad's model keeps humans close to every decision; Hello Scrum automates post-sprint.

Different philosophies: Chad's model trusts humans to catch problems at each stage. Hello Scrum trusts Hermes and automated tests to catch problems, with humans setting direction up front.
