Item Lifecycle
End-to-end — from idea to deployed code

Team Chat

Message → classify → opportunity → elaboration → sprint
1
Send message Human
Human sends a freeform message in the Team Chat panel.
2
Classify idea Haiku
AI classifies the message. If it's a story idea, returns 2 suggested titles for the human to choose from.
3
Choose title Human
Human selects one of the two suggested titles. This becomes the idea field.
idea: "Change homepage title color to red"
status: pending
opportunity: true
source: watercooler
4
Drag to Backlog Human
Human drags item from Opportunity column to Backlog on board.html. Auto-elaboration fires immediately.
5
Auto-elaboration Haiku
Haiku generates a user story and acceptance criteria from the idea. Saved to item automatically.
story: "As a product manager, I want..."
acceptance_criteria: ["h1 displays red", ...]
6
Drag to Sprint Human
Human drags item to Sprint column. Item is now queued for execution.
in_sprint: true
7
Sprint executes Sonnet
Agent implements the story guided by the acceptance criteria. Writes patches to index.html.
8
Hermes review Hermes
Hermes checks code review + AC compliance. Approve → deployed. Reject → failed.
status: done | failed
hermes_verdict: approve | reject

Inception

Intent → Unit → Stories → Bolts → sprint
1
Enter intent Human
Human enters a high-level intent on the Inception page.
2
Clarifying questions Haiku
AI generates 3 targeted questions to remove ambiguity from the intent.
3
Answer questions Human
Human answers all 3 questions to scope the work precisely.
4
Elaborate Sonnet
AI decomposes the intent into a full Unit with Stories, Bolts, NFRs, and Risks.
unit: {name, domain}
stories: [{story, idea, ac}]
bolts: [{name, story_indices}]
nfrs, risks
5
Review & edit Human
Human reviews stories, agent tasks, and AC. Edits any field before adding to sprint.
6
Add to Sprint Human
Human adds a bolt (or all stories) to the sprint. Each story becomes one sprint item with all fields stored.
idea: "Add leaderboard HTML to index.html"
story: "As a developer, I want..."
acceptance_criteria: [...]
in_sprint: true
source: inception
7
Sprint executes Sonnet
Agent implements the story guided by the acceptance criteria. The idea provides implementation context.
8
Hermes review Hermes
Hermes checks code review + AC compliance. Approve → deployed. Reject → failed.
status: done | failed
hermes_verdict: approve | reject
